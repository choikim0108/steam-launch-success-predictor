# 문서 읽는 순서

현재 작업에 필요한 핵심 문서만 `docs/` 루트에 둔다. 상세 참고 자료는 `docs/reference/`에 보관한다.

## 핵심 문서

1. `TEAM_PROJECT_PLAN.md`
   - 팀 일정, 역할 분담, 필수/보조/선택 범위

2. `DATA_COLLECTION_RUNBOOK.md`
   - 실제 데이터 수집 명령과 수집 순서

3. `DATA_COLLECTION_ATTEMPTS.md`
   - 수집 조사 결과, 429 리스크, 공식 API/SteamSpy/SteamDB 검증 기준

4. `ARCHITECTURE.md`
   - 90일 성공 예측 파이프라인과 산출물 구조

5. `MANUAL.md`
   - 명령어, 설정값, 결과 파일 위치

6. `WORKSPACE_DOCUMENTS.md`
   - 저장소 문서와 주요 경로 인덱스

## 참고 문서

`docs/reference/`에는 다음 자료를 둔다.

- 사용자 경험 상세 설계
- 프로젝트 상태 점검 기록
- 교수님/팀 회의 질문 목록
- PDF 참고 요약
- 초기 프로젝트 가이드

핵심 작업 중에는 먼저 루트의 핵심 문서만 읽고, 배경 설명이 필요할 때만 `docs/reference/`를 확인한다.
