# Steam 신작 게임 출시 성공 가능성 예측 모델

데이터마이닝 기말 프로젝트 1조 저장소입니다. 이 프로젝트는 출시 전 또는 출시 초기 정보만으로 Steam 신작 게임의 성공 가능성을 예측하고, 어떤 요인이 흥행 성공에 영향을 주는지 분석하는 것을 목표로 합니다.

## 프로젝트 개요

- 팀번호: 1조
- 팀명: 미정
- 주제: 신작 게임의 Steam 출시 성공 가능성 예측 모델
- 핵심 질문: 출시 전/초기 정보만으로 Steam 신작 게임의 흥행 가능성을 예측할 수 있는가?
- 프로젝트 방향: 모델 고도화 중심
- 최종 목표:
  - 성공/비성공 예측 모델 구축
  - 성공 요인 및 변수 중요도 분석
  - 가격, 장르, 태그, 멀티플레이 지원 여부, 언어 지원 여부 등에 따른 출시 전략 인사이트 도출

## 과제 조건

- 데이터 소스는 반드시 2종류 이상 사용
- 직접 크롤링한 데이터 반드시 포함
- 수업에서 배운 분석 방법 최대한 활용
- Classum 진행 상황 공유 시 `@박성미` 태그
- 제출 마감: 6월 15일 자정

## 데이터 계획

### 필수 데이터

1. Steam 상점/검색 페이지 직접 크롤링 데이터
   - appid, 게임명, 출시일, 가격, 장르, 태그, 개발사, 퍼블리셔, 싱글/멀티 여부, 언어 지원 여부
2. Steam Reviews API 데이터
   - 전체 리뷰 수, 긍정 리뷰 수, 부정 리뷰 수, 리뷰 작성일, 추천 여부, 플레이타임

### 보조 데이터 후보

- Metacritic 또는 OpenCritic 평점 데이터
- SteamDB 또는 SteamSpy 보조 지표
- 필요 시 RAWG, IGDB, IsThereAnyDeal 등 외부 메타데이터

## 성공 기준 후보

Steam은 실제 판매량을 공개하지 않으므로 리뷰 수와 긍정률을 흥행 대체 지표로 사용합니다.

예시 기준:

```text
success_90d = 출시 후 90일 리뷰 수 >= 500 AND 출시 후 90일 긍정률 >= 80%
```

장르별 편차가 클 경우 같은 장르/출시연도 내 90일 리뷰 수 상위 25%를 성공으로 정의하는 방안도 검토합니다.

## 분석 방법

- EDA: 성공/비성공 게임의 가격, 장르, 태그, 출시 시기, 리뷰 수, 긍정률 분포 비교
- 분류 모델: 로지스틱 회귀, 의사결정나무, 랜덤포레스트 등 비교
- 평가 지표: Accuracy, Precision, Recall, F1-score
- 해석: 변수 중요도 분석, 성공/실패 사례 비교
- 보조 분석: 필요 시 클러스터링 또는 네트워크 분석 가능성 검토

## 진행 시 주의사항

- 출시 전 예측 모델에는 출시 후 90일 리뷰 수 같은 미래 결과 변수를 입력하지 않습니다.
- Steam 실제 판매량은 직접 확보하기 어려우므로 리뷰 수, 긍정률, 리뷰 증가량을 대체 지표로 사용합니다.
- 직접 크롤링은 Steam 검색 결과의 appid 후보 수집과 Steam 상점 페이지의 유저 태그 수집에 집중합니다.
- API가 안정적으로 제공하는 리뷰 수/평점 정보는 가능하면 API를 우선 사용합니다.
