• 분석 목적이 명확한가?
• 문제 유형에 맞는 방법을 선택하였는가?
• 데이터 이해도
• 기초 통계는 충분히 확인하였는가?
• 데이터의 주요 특징을 확인하고 명확히 설명하였는가?
• 기술 난이도
• 사용한 데이터 처리/모델링/시스템 구현 방식이 도전적인가?
• 단순 API호출이 아닌 직접 설계, 구현, 기여한 바가 명확한가?
• 모델/시스템 완성도
• 모델 학습 과정이 명확히 구현되었고 시스템이 의도한 대로 완성되었는가?

• (시스템) 데이터 입력, 분석 실행, 결과 출력 과정이 하나의 시스템으로 안정적으로 구현되었는가?
