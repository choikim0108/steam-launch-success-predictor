# 구현영상 대본

## 영상 목적

이 영상은 Steam 시장 트렌드·장르 잠재력 분석 도구가 실제로 어떻게 사용되는지 설명하는 구현 영상입니다.
AI 음성이 아니라 발표자가 직접 설명하는 것을 전제로 작성했습니다.

## 1. 도입

안녕하세요. 1조는 게임 개발자가 개발하려는 게임의 장르, 태그, 가격, 언어 지원, 플랫폼 조건을 입력했을 때 현재 Steam 시장에서 어떤 추세와 전망을 갖는지 확인할 수 있는 데이터마이닝 보조도구를 만들었습니다.

이 프로젝트는 개별 게임의 성공을 단정하는 예언 모델이 아닙니다.
Steam 상점 정보, 리뷰 성과, SteamDB류 기본 정보와 비교 축을 참고해 개발자가 출시 전 기획 판단에 사용할 수 있는 시장 인사이트를 제공하는 것이 목적입니다.

## 2. 시스템 구조 설명

먼저 전체 파이프라인입니다.
Steam 상점 검색 Released_DESC 기준으로 2025년과 2026년 출시 후보 appid를 수집합니다.
그 다음 appdetails API로 가격, 장르, 카테고리, 플랫폼, 지원 언어, Steam 기능 정보를 가져옵니다.
리뷰 히스토그램을 이용해 출시 후 7일, 30일, 90일 리뷰 수와 긍정률을 계산합니다.
이후 success_90d 라벨을 만들고, Logistic Regression과 Random Forest를 비교한 뒤 HTML 리포트를 생성합니다.

## 3. 실제 활용 시나리오

이제 reports/90d/market_insight_site.html을 열어 실제 사용 흐름을 보여드리겠습니다.

첫 번째 탭은 성장 조합입니다.
여기서는 현재 표본에서 관측 성공률과 리뷰 성장 근거가 함께 확인되는 장르와 태그 조합을 확인합니다.
개발자는 이 화면을 보고 지금 시장에서 어떤 조합이 강하게 나타나는지 후보를 좁힐 수 있습니다.

두 번째 탭은 내 기획 진단입니다.
개발자가 만들려는 게임의 장르, 태그, 가격, 지원 언어 수, 플랫폼, 컨트롤러나 도전과제 같은 기능을 입력합니다.
그러면 선택 조건에 맞는 관측 성공 사례와 실패 또는 주의 사례를 함께 비교할 수 있습니다.
이 부분이 SteamDB와 다른 점입니다.
SteamDB가 개별 게임의 현황과 기본 정보를 보여준다면, 이 도구는 여러 게임의 관측 데이터를 묶어 개발 전 기획 조건을 비교하게 해줍니다.

세 번째 탭은 근거 사례입니다.
성공 사례만 보여주지 않고 실패 또는 주의 사례도 같이 보여줍니다.
개발자는 비슷한 실패 사례를 보면서 출시 전 리스크 체크리스트를 만들 수 있습니다.

네 번째 탭은 판단 기준입니다.
여기서는 모델 feature importance, 성공·중박·실패 기준, 모델과 파이프라인 구조를 확인합니다.

## 4. 모델 비교 분석 설명

모델은 Logistic Regression과 Random Forest를 비교했습니다.
현재 데이터는 총 22,473개이고, success_90d 성공 라벨은 636개입니다.
성공 라벨 비율은 2.8%로 낮기 때문에 Accuracy 하나만 보면 안 됩니다.

Logistic Regression의 Accuracy는 0.754, F1은 0.134, ROC-AUC는 0.789입니다.
Random Forest의 Accuracy는 0.827, F1은 0.178, ROC-AUC는 0.821입니다.
Random Forest가 F1과 ROC-AUC에서 더 좋아 최종 모델로 선택했습니다.

다만 Precision은 낮습니다.
따라서 이 모델은 성공을 확정하는 도구가 아니라, 성공 가능성이 상대적으로 높아 보이는 기획 조건과 참고 사례를 찾는 보조도구로 해석해야 합니다.

## 5. 활용 방안과 한계

활용 방안은 출시 전 체크리스트입니다.
예를 들어 개발자가 RPG 또는 Simulation 계열 게임을 준비한다면, 이 도구로 유사 장르의 관측 성공률, 가격대, 언어 지원 수, Steam 기능 지원 여부, 성공 사례와 실패 사례를 비교할 수 있습니다.

한계도 있습니다.
Steam은 실제 판매량을 공개하지 않기 때문에 본 프로젝트는 리뷰 수와 긍정률을 흥행 proxy로 사용했습니다.
리뷰 수는 판매량과 같지 않으므로 결과를 실제 매출 예측으로 과장하지 않습니다.
향후에는 SteamDB류 플레이어 수, SteamSpy owners, 유튜브 언급량, 웹진 기사, 외부 이슈, 리뷰 토픽 분석을 추가하면 더 설득력 있는 시장 인사이트 도구로 개선할 수 있습니다.

## 6. 마무리

정리하면, 이 프로젝트는 Steam 공개 데이터를 활용해 게임 개발자가 자기 기획의 시장 추세와 전망을 확인하는 보조도구입니다.
문제 정의, 데이터 수집, 데이터 정제, 데이터 탐색, 모델 비교, 결과 활용까지 하나의 파이프라인으로 연결했고, 최종 결과는 HTML 리포트와 PDF 보고서로 확인할 수 있습니다.
